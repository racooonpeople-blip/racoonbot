# Racooon web v0.1

First working landing-page scaffold for Racooon.

## Run locally

```bash
cd web
npm install
npm run dev
```

Open http://localhost:3000.

## Current scope

- responsive landing page
- functional file picker UI
- public-link input UI
- interface-language menu
- expanded supported-language strip
- use-case cards
- feature and workflow sections

The hero raccoon is a temporary CSS placeholder. The approved mascot artwork will be added as a proper asset next.
